# 🌍 Decent Work & Economic Growth

A responsive **static website** built using **HTML and CSS** to spread awareness about **UN Sustainable Development Goal 8 (SDG 8)** — *Decent Work and Economic Growth*. The project highlights why inclusive growth matters and showcases real-world focus areas like green jobs, worker rights, and digital skills.

This project is well-suited for **college assignments, SDG-based projects, hackathons, and beginner portfolios**.

---

## 📌 Project Objective

The goal of this website is to:

* Educate users about **SDG Goal 8**
* Explain the importance of decent work and economic growth
* Present real-world stories related to employment and sustainability
* Practice clean UI design using only HTML and CSS

---

## ✨ Features

* 🧭 Simple navigation bar (Home, About, Gallery, Contact)
* 🎯 Hero section with clear SDG messaging
* 📖 “Why It Matters” informational section
* 🖼️ Story-based gallery cards
* 📱 Responsive design using CSS Grid & media queries
* 🎨 Clean typography and color contrast

---

## 🛠️ Tech Stack

* **HTML5** – Page structure and content
* **CSS3** – Styling, layout, and responsiveness
* **Google Fonts (Roboto)** – Typography

> ⚠️ No JavaScript or backend used — this is a fully static website.
